# HOMEY – إصلاح واجهة لوحة التحكم على الكمبيوتر والموبايل

## التثبيت
1. احتفظ بنسخة احتياطية من ملفات المشروع الحالية.
2. انسخ محتويات المجلد `src` من هذه الحزمة فوق مجلد `src` الموجود في مشروع HOMEY، واستبدل الملفات المطابقة.
3. نفّذ `npm run build` في مشروعك الكامل لو عندك ملفات `package.json` ومكتباته مثبتة، ثم ارفع النسخة على Vercel.
4. اعمل Hard Refresh (Ctrl+F5) من صفحة لوحة التحكم بعد النشر.

## ما تم إصلاحه
- حل مشكلة تداخل روابط الشريط الجانبي مع روابط معاينة المتجر وتسجيل الخروج عند شاشات الكمبيوتر القصيرة أو تكبير المتصفح؛ أصبح شريط التنقل قابلًا للتمرير بشكل مستقل.
- ضبط عرض الشريط الجانبي على الكمبيوتر، ومساحة لوحة العمل، والعناوين والأزرار والجداول.
- زر تصغير / توسيع الشريط الجانبي على الديسكتوب، ويحتفظ بالاختيار في المتصفح.
- عند عرض نافذة ضيقة (900px أو أقل) تظهر قائمة جانبية قابلة للفتح والإغلاق بدلًا من ضغط المحتوى.
- تنقلات أكثر وضوحًا وترتيب منطقي، مع الحفاظ على اللوجو الحالي كما هو.
- أُبقيت إصلاحات المحافظات والشحن المجاني وحذف طلبات التجربة من آخر إصدار مستخدم بدون تغيير.

## SQL
ملف SQL السابق موجود في `sql` للاحتفاظ بإصدار كامل من الحزمة. **هذا الإصلاح بصري فقط ولا يتطلب تشغيل SQL مرة أخرى**.

## الاختبار بعد النشر
- افتح `/admin` على ديسكتوب (1920 و1366 و1024 بكسل)، جرّب تغيير ارتفاع النافذة إلى نحو 600px وتكبير الصفحة إلى 125%.
- جرّب تصغير وتوسيع الشريط الجانبي، والتنقل بين الصفحات والعودة.
- جرّب `/admin/orders`, `/admin/products`, `/admin/settings`، وتأكد أن الجداول يمكن تمريرها أفقيًا لو الشاشة ضيقة.
- جرّب شاشة أقل من 900px: افتح القائمة وأغلقها من زر X أو خارجها أو Escape.

**ملحوظة:** الاختبارات الحية للواجهة تتطلب تشغيل المشروع على سيرفرك مع بيانات حساب الإدارة؛ لم يتم تعديل بيانات Supabase.
