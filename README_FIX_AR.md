تحديثات واجهة هومي:
1- إصلاح حفظ الصور: عند فتح منتج قديم تظهر صور Supabase العامة، وعند حفظه تتحول إلى مسارات Storage الصحيحة دون إعادة رفعها. الصور الجديدة تُحفظ بمساراتها.
2- رفع صور متعددة وإعادة ترتيبها موجودان؛ تمت إضافة تمييز الصورة الرئيسية وتحسين النصوص.
3- إصلاح توليد التفريعات عند كتابة القيم ثم الضغط على زر التوليد مباشرة دون الخروج من الحقل.
4- صور كروت المنتجات تظهر كاملة دون قص.
5- تحسين فك ترميز الصور غير المتزامن.
6- مسار الطلب الحالي يستخدم homly_checkout، وتظهر تفاصيل الطلب ورسالة واتساب بعد نجاح الحفظ. لا يمكن ضمان عمله على قاعدة البيانات الحية دون التحقق من تعريف الدالة والسياسات؛ ملف SQL المرفق تشخيصي آمن ولا يغيّر قاعدة البيانات.
مهم: هذا ZIP يحتوي مجلد src فقط (مثل السورس الذي رفعته)، وليس مشروع Vite كاملًا. احتفظ بنسخة احتياطية قبل استبدال src.
